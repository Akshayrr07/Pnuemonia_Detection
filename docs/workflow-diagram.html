Inference Workflow

How a chest X-ray becomes a structured prediction — from upload to response

1
Upload
User selects a chest X-ray (JPEG/PNG, ≤ 10 MB) on the Next.js frontend
▼
2
Validation
Backend checks file type, extension, size, and that the image can actually be decoded. Corrupt files → 400.
▼
3
Preprocessing
Image resized and normalized to the same transforms used during training (ImageNet stats, 224×224)
▼
4
⚡ Stage 1 — Normal vs Pneumonia
Hugging Face Inference API call to the binary model. Threshold = 0.50 (configurable).
├─ Normal
▼
5a
Return Normal
Subtype skipped — no pneumonia detected. Confidence and probabilities returned.
▼
6a
Final response — No pneumonia
└─ Pneumonia
▼
5b
⚡ Stage 2 — Bacterial vs Viral
Only if Stage 1 detected pneumonia. HF Inference API call to subtype model.
▼
6b
Return subtype
Bacterial or Viral, with confidence and per-class probabilities.
▼
7
Final response — Pneumonia + subtype
▼
📦
Structured JSON response
Primary prediction, confidence, subtype (if applicable), full probability map, model outputs, medical disclaimer
{ "primary_prediction": "Pneumonia", "primary_confidence": 0.93, "subtype_prediction": "Bacterial Pneumonia", "subtype_confidence": 0.76, "probabilities": { "Normal": 0.07, "Pneumonia": 0.93, "Bacterial Pneumonia": 0.76, "Viral Pneumonia": 0.24 }, "disclaimer": "This result is for educational support only…" }
Optional explainability: when LOCAL_MODEL_PATH is set, Grad-CAM runs locally on the loaded checkpoint and the heatmap is returned as heatmap_b64.
