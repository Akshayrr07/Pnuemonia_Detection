# Compatibility shim for existing research/demo commands.
# Runtime dependencies are intentionally declared by the separate backend and
# research requirement inputs:
#   backend/requirements.in       (production API)
#   requirements-research.in      (training/evaluation/experiments)
#
# For the supported Python 3.11 runtime, install one of:
#   uv pip install -r backend/requirements.txt   (production API)
#   uv pip install -r requirements.txt           (legacy research/demo set)
#
# This compatibility file preserves the historical research behavior; API and
# Docker deployments should install backend/requirements.txt explicitly.
-r requirements-research.txt
